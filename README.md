# Clinical Nutrition SharePoint site: practice demo

A clickable mockup of a SharePoint communication site for a hospital dietitian team, built so people can practice getting around before the real site exists.

Unit numbers are real; **every guideline is blank and for display purposes only.** Nothing on this site is medical guidance. Hatched buttons are display only.

- Live demo: https://kleynhoyz.github.io/rd-sharepoint-demo/
- Desktop layout only.
- Everything shown can be built in SharePoint Online by a regular site owner with out-of-box features: no code and no admin rights. Open "SharePoint build notes" at the bottom of any page to see how.

This repo holds only the built page (`index.html`). The source lives in a separate private repo; don't edit this file by hand.
